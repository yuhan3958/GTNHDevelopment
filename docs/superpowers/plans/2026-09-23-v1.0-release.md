# v1.0 Unified UX and Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate all milestone features into a coherent UX, complete documentation, and produce verified v1.0 release artifacts.

**Architecture:** One Tool Window composes independent feature panels and immutable service snapshots. Release work changes no analysis semantics except defects exposed by acceptance testing.

**Tech Stack:** JetBrains UI components/UI DSL, Gradle buildPlugin, Plugin Verifier, IntelliJ test framework.

**Spec:** `docs/superpowers/specs/2026-09-23-gtnh-development-v1-design.md`

## Global Constraints

- Preserve provider/service boundaries.
- Do not add new unplanned subsystems during release cleanup.
- Do not publish or tag without explicit user authorization.

## Review Focus

- Tool Window remains usable when every optional feature is disabled.
- Refreshes from multiple panels cannot update disposed projects.
- Keyboard and screen-reader labels cover navigation actions.
- Plugin metadata accurately states required dependency and compatibility.
- Release notes contain only verified behavior.
