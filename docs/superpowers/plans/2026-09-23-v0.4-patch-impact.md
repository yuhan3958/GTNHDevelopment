# v0.4 Patch Impact Explorer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Find Mixin, obvious ASM, and Access Transformer modifications affecting a selected class or method.

**Architecture:** `GtnhPatchService` aggregates independent providers. Findings carry navigatable evidence and `EXACT` or `HEURISTIC` confidence. Minecraft Development access remains behind an adapter.

**Tech Stack:** Kotlin, IntelliJ PSI, file indexes, native popup/tree UI.

**Spec:** `docs/superpowers/specs/2026-09-23-gtnh-development-v1-design.md`

## Global Constraints

- Do not duplicate Minecraft Development inspections.
- Never label string/ASM heuristics as exact.
- Run discovery off EDT with cancellation.

## Review Focus

- Overloaded target methods retain selector context.
- Unresolved annotation values do not crash analysis.
- ASM strings outside transformer context do not become findings.
- Malformed AT lines are ignored and logged at diagnostic level.
- Provider failure does not discard other provider results.
